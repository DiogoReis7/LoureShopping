# LoureShopping — refazer tudo (GitHub + Vercel)

1. Coloca TODO o conteúdo desta pasta na raiz de um repositório novo no GitHub.
2. No Vercel: Add New > Project > importa esse repositório.
3. Antes do Deploy, adiciona as 7 variáveis (ver .env.example).
4. Deploy. Se mudares variáveis depois: Deployments > Redeploy (sem cache).
